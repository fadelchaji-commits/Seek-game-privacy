دليلي الخاص في كالي لينكس 🛡️

مشروعي الأول لتوثيق الأدوات والأوامر البرمجية

1. إدارة الملفات والحزم (File & Package Management)
الأمر (Command) الشرح بالعربية (Description)
apt update && apt upgrade تحديث مستودعات النظام وترقية الحزم المثبتة إلى آخر إصدار.
tar -cvf archive.tar folder/ ضغط مجلد معين بصيغة tar.
tar -xvf archive.tar فك ضغط ملف بصيغة tar.
zip -r file.zip folder/ ضغط المجلدات والملفات بصيغة zip المعتادة.
unzip file.zip فك ضغط الملفات المفتوحة بصيغة zip.
xsltproc أداة لتحويل ملفات XML (مثل تقارير Nmap) إلى صفحات HTML مرئية.
2. فحص الشبكات والحماية (Networking & Recon)
الأداة / الأمر (Tool / Command) الشرح بالعربية (Description)
ifconfig عرض إعدادات بطاقة الشبكة ومعرفة عنوان IP الخاص بجهازك.
nmap -version التحقق من إصدار أداة Nmap المثبتة على النظام.
nmap [IP_Address] عمل فحص ذكي للمنافذ المفتوحة (Ports) على الجهاز المستهدف.
msfconsole تشغيل إطار عمل Metasploit للبحث عن الثغرات واختبار الاختراق الأخلاقي.
3. التعامل مع GitHub (Git Commands)
الأمر (Command) الشرح بالعربية (Description)
git clone [URL] تحميل أو نسخ مستودع (Repository) من موقع GitHub إلى جهازك.
git add . تجهيز جميع الملفات الجديدة أو المعدلة داخل المجلد لرفعها.
git commit -m "Message" حفظ التغييرات محلياً مع كتابة رسالة توضيحية لما قمت بتعديله.
git push origin main رفع الملفات والتعديلات نهائياً من جهازك إلى مستودعك على GitHub.
